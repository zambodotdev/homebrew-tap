# Zambo Homebrew tap

## Install aer1-scan

```bash
brew tap zambodotdev/tap
brew install aer1-scan
```

`aer1-scan` checks every Zambo receipt link in a file or page and reports which ones verify (AER-1, draft-zambo-aer1-26).

```bash
aer1-scan path/to/file.md
aer1-scan https://example.com/page-with-receipts
```

Free service, get Zambo: https://zambo.dev/add/?ref=homebrew-tap
Check a receipt: https://zambo.dev/verify/
